# Repositorio personal de la materia de Construcción de Software y Toma de Decisiones
## main branch
Contiene todo lo trabajado tanto individual como colaborativamente a lo largo del curso.
+ apuntesLecturas: apuntes de las lecturas de temas vistos a lo largo del curso.
+ avancesProyecto: archivos correspondientes a las entregas formales de los avances del proyecto (colaborativo) de la materia.
+ trabajosDePractica: ejercicios y casos de estudio del curso, realizados individual o en equipo.
+ oldLabs: archivos de laboratorios personales anteriores.

## develop branch
Contiene los archivos del progreso acumulativo de los laboratorios: una aplicación web que usa los temas vistos a lo largo de todos los laboratorios hasta el momento. Se usa siempre como punto de partida para el desarrollo del código de los siguientes laboratorios (en nuevas branches con el nombre del lab).
Las carpetas y archivos siguen una arquitectura MVC, por lo que incluye carpetas de vistas, controllers y modelos, además de rutas, el gestor de paquetes package.json y otros elementos personales para el sitio (css, htmls, etc.).

## lab(n) branch
Ramas que contienen los archivos correspondientes al laboratorio indicado en el nombre (n).
